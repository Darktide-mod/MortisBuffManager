# 死靈試煉 Buff 管理器 — 三種玩法

死靈 Buff 管理器以 SoloPlay 為前提，同時支援 Realms。可以開局前預選原版死靈 Buff，也可以按地圖進度抽選，或透過個人擊殺競爭抽選獎勵。房主為全隊設定統一模式和 0–64 個 Buff 上限。天賦點管理器為可選模組。

## 三種全域性模式

- 點數預選：進入任務前開啟天賦樹選擇 Buff，全隊使用同一點數上限，允許設為零。每個 Buff 消耗一點。列表提供分類、僅看已選、原版圖示和詳情欄；流派、職業、技能及天賦限制遵循原版資料。
- 進度抽選：開局獲得一次三選一；此後首次越過主路線 10% 至 90% 的每個 10% 進度節點，以及完成主線目標時，獲得後續機會。死靈試煉使用完成波次。不會按時間發放獎勵；點數是上限，較短任務不保證能拿滿。
- 競爭模式：開局同樣抽選一次。每人的擊殺獨立累計進度，小兵和屍潮 0.25%、特感 5%、精英 2.5%、Boss 50%；達到 100% 向該玩家發放一次機會，溢位進度保留。房主可在 DMF 全域性修改四類權重。Bot 的擊殺不會算給真人玩家。

## 戰鬥中三選一

螢幕上方出現三張緊湊卡片，用 Ctrl+1、Ctrl+2、Ctrl+3 選擇。入場滑動、選中高亮和淡出展示抽選結果。不會停止角色、搶佔滑鼠或開啟原版強制選取彈窗；其他選單和文字輸入優先。

每次選擇有 60 秒，超時由房主隨機選取。新機會排在當前選擇之後，每輪重新獲得完整 60 秒；同時到達多個機會也不會一起倒計時。候選不重複，也排除已經獲得的 Buff。剩餘合法候選不足三個時只顯示可用項，池子耗盡後停止抽選。

按 Tab 可以在原版死靈分類中檢視自己實際獲得的 Buff；候選和排隊中的獎勵不會被算作已獲得。兩種抽選模式下，天賦樹中的死靈入口置灰，並顯示同步後的獎勵數量。點數模式進入任務後鎖定編輯。

競爭模式在作戰畫面下方中央持續顯示小型個人進度，抽選卡片出現期間也保留。在 DMF 可選擇四種樣式：小型進度條、小型進度條＋百分比（預設）、僅百分比、不顯示，切換立即生效；隱藏進度不影響抽選卡片和進度累計。這是個人顯示偏好，不修改房主的全域性模式、權重或點數。

## Realms 管理與部署狀態

準備介面頂部提供一行全域性死靈設定：功能開關、共同點數上限和模式。房主剛建立空房間就能使用。數字支援點選輸入和貼上，回車或點選別處確認，Esc 取消；加減按鈕長按 400 毫秒後連續調整。死靈不提供逐玩家模式和點數覆蓋。

每位玩家下方顯示死靈模組部署狀態：等待通訊、已就緒、載入資源中、已關閉、未安裝或不相容、未響應、連線中斷。收到版本資訊時顯示版本號；持續異常會向房主提示，同一狀態不會每幀重複提示。“未安裝或不相容”不能精確區分未裝模組和舊協議，應檢查客機安裝情況。

與天賦點管理器 2.2.1 同時啟用時，同一列表會保留逐玩家天賦控制元件和天賦部署狀態。兩個模組的行和數字輸入互相相容；四人列表使用 Realms 原生捲軸。客機看不到房主管理欄。未安裝 Realms 時使用 DMF 模組選項，聯機介面功能保持靜默。

## 加入、掉線與規則修改

房主決定候選、佇列和實際獎勵。客機確認已啟用模組且原版資源就緒後，才會接收這些 Buff。資源未就緒、關閉模組或掉線隻影響對應玩家，其他玩家繼續正常抽選。中斷期間暫停該玩家當前卡片和剩餘時間；同一任務中回到相同房間與角色時保留已得獎勵。不同角色、不同任務獨立記錄。

拒絕舊會話選擇、重複選擇和過期回覆；重連握手與定期同步可恢復丟失訊息。房主通訊超時後，客機停止使用舊規則。這不提供房主遷移，也不保留房間關閉後的任務記錄。

降低全域性上限會限制實際生效的 Buff，但保留原有預選或本局選擇歷史；之後提高上限可恢復保留項。任務途中切換獎勵模式會重新開始該模式的抽選記錄，建議開局前完成模式設定。

## 安裝要求

必需：Darktide Mod Loader、Darktide Mod Framework、SoloPlay。Realms 用於玩家房主聯機。房主和參與抽選的客機請統一使用 MortisBuffManager 3.0.0。需要同時顯示兩套管理介面時，也將 TalentPointManager 更新到 2.2.1；兩個模組可獨立安裝。

## Vortex 安裝

- 退出遊戲並安裝依賴。
- 下載 Files 中的安裝 ZIP，在 Vortex 使用 Install From File，啟用後執行 Deploy Mods。
- 在 Load Order 啟用 MortisBuffManager，放在 SoloPlay 之後；聯機時同時啟用 Realms。
- 重啟，在模組選項 → 死靈試煉 Buff 管理器中啟用自定義 Buff，再設定模式和上限。

## 手動安裝

- 退出遊戲並安裝依賴。
- 將 ZIP 中的 MortisBuffManager 資料夾解壓到 Darktide/mods，得到 mods/MortisBuffManager。
- 在 mods/mod_load_order.txt 的 SoloPlay 後面單獨新增一行 MortisBuffManager。
- 重啟並在模組選項啟用功能。同一時間只安裝本模組的一個版本。

## 預設值與相容性

DMF 開關與本模組功能總開關都需要開啟。功能預設關閉，預設點數預選、全域性上限 32；保留原有角色預選。關閉 DMF 後清理本模組介面、輸入狀態及生效效果，儲存的選擇仍會保留。

使用原版 Buff 模板、編號和任務 Buff 管理器，繼續遵循原版疊加與可選性規則；並不保證全部原版效果彼此疊加。當本模組管理死靈試煉任務時，將接管原版獎勵選擇，避免原版彈窗強制接管操作。其他替換相同獎勵流程的模組可能衝突。本模組不改變官方匹配中的永久進度。
