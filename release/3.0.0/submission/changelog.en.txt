3.0.0

- Add global preselection, mission-progress draft and personal kill competition modes; shared limit 0–64.
- Give an opening pick in both draft modes; default kill progress is 0.25% regular/horde, 5% special, 2.5% elite, 50% boss.

- Add one Realms global rule row, per-player deployment/version status and host notices; clients follow host authority.
- Pause affected-player choices on disconnect or resource loss, reject stale sessions, and retain same-mission character choices on reconnect.
- Preserve native templates/IDs and Tab Buff presentation; retain DMF-disable/resource cleanup fixes.
- Support TalentPointManager 2.2.1 controls in either loading order, repeated rooms and separate enable/disable.
- Update three-language UI/docs; local native-backed and simulated checks passed. Live multiplayer testing remains necessary.
