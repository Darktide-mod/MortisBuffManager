[size=5][b]死灵试炼 Buff 管理器 — 三种玩法[/b][/size]

死灵 Buff 管理器以 SoloPlay 为前提，同时支持 Realms。可以开局前预选原版死灵 Buff，也可以按地图进度抽选，或通过个人击杀竞争抽选奖励。房主为全队设置统一模式和 Buff 上限（进度模式 0–10，其他模式 0–64）。天赋点管理器为可选模组。

[size=4][b]三种全局模式[/b][/size]

[list]
[*]点数预选：进入任务前打开天赋树选择 Buff，全队使用同一点数上限，允许设为零。每个 Buff 消耗一点。列表提供分类、仅看已选、原版图标和详情栏；流派、职业、技能及天赋限制遵循原版数据。
[*]进度模式：开局从三条原版公共路线中选一条，立即获得该路线的基础 Buff。后续路线奖励自动发放，第 4、7、10 个奖励为原版传奇三选一。包含开局 Buff 在内最多 10 个。主路径节点为 8%、16%、24%、32%、40%、50%、60%、70%、80%，最后一份奖励提前发放。没有线性路径的地图使用主线目标开始事件作为阶段补充；路径与目标不会重复计数。死灵试炼使用波次事件，不按时间发奖。
[*]竞争模式：开局选路线；个人击杀进度每达到 100%，自动随机发放该路线的一个 Buff，基础 Buff 优先。路线耗尽后自动发放适用于当前角色的公共／职业 Buff，不安排波次传奇三选一，也不混入其他路线或重复奖励。保留溢出进度。小兵和尸潮默认 0.25%、特感 5%、精英 2.5%；普通 Boss、虚弱 Boss、连长／双子分别设置，初始均为 50%。Bot 的击杀不会算给真人玩家。
[/list]

[size=4][b]路线与传奇选择[/b][/size]

屏幕上方出现三张紧凑卡片，用 Ctrl+1、Ctrl+2、Ctrl+3 选择。入场滑动、选中高亮和淡出展示抽选结果。不会停止角色、抢占鼠标或打开原版强制选取弹窗；其他菜单和文字输入优先。

开局路线选择与进度模式的传奇选择均有 60 秒，超时由房主随机选取。新机会排在当前选择之后，每轮重新获得完整 60 秒；同时到达多个机会也不会一起倒计时。候选不重复，也排除已经获得的 Buff。剩余合法候选不足三个时只显示可用项，池子耗尽后停止抽选。

按 Tab 可以在原版死灵分类中查看自己实际获得的 Buff；候选和排队中的奖励不会被算作已获得。进度和竞争模式下，天赋树中的死灵入口置灰，并显示同步后的奖励数量。点数模式进入任务后锁定编辑。

竞争模式在作战画面下方中央持续显示小型个人进度，抽选卡片出现期间也保留。在 DMF 可选择四种样式：小型进度条、小型进度条＋百分比（默认）、仅百分比、不显示，切换立即生效；隐藏进度不影响抽选卡片和进度累计。这是个人显示偏好，不修改房主的全局模式、权重或点数。

[size=4][b]Realms 管理与部署状态[/b][/size]

DMF 的击杀进度数字支持两位小数，数字框常驻显示：可输入或粘贴，回车或点击别处确认，Esc 取消。虚弱 Boss 使用原版弱化标记识别；连长和双子优先归入独立类别。

准备界面顶部提供一行全局死灵设置：功能开关、共同点数上限和模式。房主刚创建空房间就能使用。数字支持点击输入和粘贴，回车或点击别处确认，Esc 取消；加减按钮长按 400 毫秒后连续调整。死灵不提供逐玩家模式和点数覆盖。

每位玩家下方显示死灵模组部署状态：等待通信、已就绪、加载资源中、已关闭、未安装或不兼容、未响应、连接中断。收到版本信息时显示版本号；持续异常会向房主提示，同一状态不会每帧重复提示。“未安装或不兼容”不能精确区分未装模组和旧协议，应检查客机安装情况。

与天赋点管理器 2.2.2 同时启用时，同一列表会保留逐玩家天赋控件和天赋部署状态。两个模组的行和数字输入互相兼容；四人列表使用 Realms 原生滚动条。客机看不到房主管理栏。未安装 Realms 时使用 DMF 模组选项，联机界面功能保持静默。

[size=4][b]加入、掉线与规则修改[/b][/size]

房主决定候选、队列和实际奖励。客机确认已启用模组且原版资源就绪后，才会接收这些 Buff。资源未就绪、关闭模组或掉线只影响对应玩家，其他玩家继续正常抽选。中断期间暂停该玩家当前卡片和剩余时间；同一任务中回到相同房间与角色时保留已得奖励。不同角色、不同任务独立记录。

拒绝旧会话选择、重复选择和过期回复；重连握手与定期同步可恢复丢失消息。房主通信超时后，客机停止使用旧规则。这不提供房主迁移，也不保留房间关闭后的任务记录。

降低全局上限会限制实际生效的 Buff，但保留原有预选或本局选择历史；之后提高上限可恢复保留项。任务途中切换奖励模式会重新开始该模式的抽选记录，建议开局前完成模式设置。

[size=4][b]安装要求[/b][/size]

必需：Darktide Mod Loader、Darktide Mod Framework、SoloPlay。Realms 用于玩家房主联机。房主和参与抽选的客机请统一使用 MortisBuffManager 3.1.0。需要同时显示两套管理界面时，也将 TalentPointManager 更新到 2.2.2；两个模组可独立安装。

[size=4][b]Vortex 安装[/b][/size]

[list]
[*]退出游戏并安装依赖。
[*]下载 Files 中的安装 ZIP，在 Vortex 使用 Install From File，启用后执行 Deploy Mods。
[*]在 Load Order 启用 MortisBuffManager，放在 SoloPlay 之后；联机时同时启用 Realms。
[*]重启，在模组选项 → 死灵试炼 Buff 管理器中启用自定义 Buff，再设置模式和上限。
[/list]

[size=4][b]手动安装[/b][/size]

[list]
[*]退出游戏并安装依赖。
[*]将 ZIP 中的 MortisBuffManager 文件夹解压到 Darktide/mods，得到 mods/MortisBuffManager。
[*]在 mods/mod_load_order.txt 的 SoloPlay 后面单独添加一行 MortisBuffManager。
[*]重启并在模组选项启用功能。同一时间只安装本模组的一个版本。
[/list]

[size=4][b]默认值与兼容性[/b][/size]

DMF 开关与本模组功能总开关都需要开启。功能默认关闭，默认点数预选、全局上限 32；保留原有角色预选。关闭 DMF 后清理本模组界面、输入状态及生效效果，保存的选择仍会保留。

使用原版 Buff 模板、编号和任务 Buff 管理器，继续遵循原版叠加与可选性规则；并不保证全部原版效果彼此叠加。当本模组管理死灵试炼任务时，将接管原版奖励选择，避免原版弹窗强制接管操作。其他替换相同奖励流程的模组可能冲突。本模组不改变官方匹配中的永久进度。

[size=4][b]3.1.0 验证情况[/b][/size]

原版源码对照覆盖 128 组职业／闪击／战斗技能配置、七条路线、基础奖励和传奇权重。本地检查覆盖实际 Lua 队列与通信逻辑、原版 Buff 应用接口、Tab 收集、DMF 开关、Realms 加载、两套控件共存、三语和 16:9、16:10、21:9、4:3 等常见比例。卡片比最初预览减少约 41% 面积；长说明自动缩小，仍过长时使用原版省略处理。

图片为离线界面布局渲染，Buff 文案、玩家和数值为示例，并非游戏实拍。游戏素材由游戏提供，安装包不含提取的图片资源。本次仍需要游戏内及实际联机复测。
