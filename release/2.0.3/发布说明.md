安装 ZIP 的最外层只有 MortisBuffManager/，不含其他模组或嵌套压缩包。

Vortex：管理 Darktide → Install From File 导入此 ZIP → 启用 → Deploy Mods → 调整 Load Order。

手动：将 ZIP 解压到 Darktide/mods，得到 mods/MortisBuffManager；在 mod_load_order.txt 中添加此模组名称。

必需依赖：Darktide Mod Loader、Darktide Mod Framework、Solo Play

可选依赖：Realms — for player-hosted sessions

具体加载顺序见三语正文。PNG 单独上传 Images，文案复制到页面；只将 files 中的 ZIP 上传 Files。

修复 DMF 禁用后进入天赋树出现无法关闭的空弹窗及残留入口。原版控件默认可见，因此现在控件内容默认隐藏，绘制与交互也检查框架状态。 独立安装包；三语说明与检查记录。本地回归通过，尚未实机复测。

此流程不会部署游戏文件或上传 Nexus。服务器扫描在实际上传后进行。
