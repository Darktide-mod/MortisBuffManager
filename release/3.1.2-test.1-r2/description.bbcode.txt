[size=5][b]English[/b][/size]

[size=5][b]Mortis Trials Buff Manager[/b][/size]

Bring native Mortis Buffs into SoloPlay and Realms missions. The host selects one reward mode and one shared Buff limit for the party. Three modes provide preselected builds, map-progress rewards or personal kill rewards.

[size=4][b]Preselection[/b][/size]

Open the talent tree before a mission and choose Buffs using category filters, a selected-only view, native icons and a detail panel. Each Buff costs one point; the shared limit is 0–64. Family, class, ability and talent requirements follow native data. Editing is locked once the mission begins.

[size=4][b]Progress mode[/b][/size]

At the start, choose one of three shared Mortis routes and immediately receive its foundation Buff. Further route Buffs are automatic. Legendary three-way choices occur at reward slots 4, 7 and 10.

The total limit is 10 Buffs, including the opening reward. Path milestones are 8%, 16%, 24%, 32%, 40%, 50%, 60%, 70% and 80%, so the final reward arrives before the mission ends. Maps without a linear path use main objective starts for bounded stage rewards. Path and objective rewards do not double-count; Mortis Trials uses wave events. Elapsed time does not grant rewards.

[size=4][b]Competition mode[/b][/size]

Choose a route at the start. Each player then earns personal progress from kills. Every 100% grants an automatic Buff from the chosen route, prioritizing foundation Buffs. When that route is exhausted, further earned rewards offer compatible public/class Buffs as three-way choices, without a wave schedule. Acquired Buffs are excluded from future choices. The shared limit is 0–64 and overflow progress is retained.

Default kill progress: regular enemies/hordes 0.25%, specialists 5%, elites 2.5%, ordinary bosses 50%, weakened bosses 50%, captains/twins 50%. The host can adjust all six categories globally with two decimal places. Bot kills do not award a human player's progress.

Choose a local combat indicator in DMF: small bar, bar + percentage, percentage only, or hidden. Hiding the indicator does not stop rewards or hide choice cards.

[size=4][b]Route and Buff choices[/b][/size]

Three compact animated cards appear above the centre of the screen. Press Ctrl+1, Ctrl+2 or Ctrl+3 to choose. Choices do not stop movement or capture the mouse; other menus and text entry take priority.

Each choice allows 60 seconds, after which the host chooses randomly. Further opportunities queue behind the active choice, each receiving a fresh 60 seconds. Candidates follow native route and class eligibility. If fewer than three remain, only eligible entries are offered; an exhausted pool stops further choices.

Press Tab to view acquired Buffs in the native Mortis category. In progress and competition modes, the talent-tree Mortis button is disabled and displays synchronized reward counts.

[size=4][b]Host settings and Realms[/b][/size]

Without Realms, configure the mode, shared limit and kill weights through DMF. With Realms, the host has one global Mortis control row in the preparation list, including in an empty room. Per-player mode and point overrides are not provided. The row can coexist with Talent Point Manager's individual controls.

Click numeric settings to type or paste. Enter or clicking elsewhere confirms; Esc cancels. Realms plus/minus controls repeat after a 400 ms hold.

Guests follow host rules. Deployment indicators show readiness, missing/incompatible installations, resource loading, disabled state and lost connections. An unready or disconnected guest does not block the remaining players. Rejoining the same room and character during a mission retains acquired rewards; another character or mission has separate state. The host owns choices and rewards, and stale or duplicate replies cannot consume another reward. Host migration is not provided.

Reducing the limit restricts active Buffs while retaining saved choices; raising it can restore them. Changing reward mode during a mission starts a new reward run. Configure the intended mode before starting.

[size=4][b]Requirements and compatibility[/b][/size]

Requires Darktide Mod Loader, Darktide Mod Framework and SoloPlay. Realms is optional for player-hosted co-op. Talent Point Manager is optional. English, Simplified Chinese and Traditional Chinese follow the game language.

Enable both the DMF switch and custom Mortis Buffs. The feature defaults off, with preselection and a 32-point shared limit. Disabling the mod removes its UI and applied effects while retaining saved choices.

Buffs use original game templates, identifiers and the mission-Buff manager. Native stacking and eligibility rules apply. When managing Mortis Trials, this mod handles rewards without the native modal picker. Other mods replacing the same reward flow can conflict. The mod does not alter permanent progression in official matchmaking.

[size=4][b]Vortex installation[/b][/size]

[list]
[*]Close the game and install the requirements. Import the ZIP with Install From File, enable it and select Deploy Mods.
[*]Place MortisBuffManager after SoloPlay in Load Order; enable Realms for co-op.
[*]Start the game and enable custom Mortis Buffs in Mod Options, then choose a mode and limit.
[/list]

[size=4][b]Manual installation[/b][/size]

[list]
[*]Close the game. Extract the ZIP into Darktide/mods, producing mods/MortisBuffManager.
[*]Add MortisBuffManager on its own line after SoloPlay in mods/mod_load_order.txt.
[*]Start the game and enable the feature in Mod Options.
[/list]

[size=5][b]简体中文[/b][/size]

[size=5][b]死灵试炼 Buff 管理器[/b][/size]

在 SoloPlay 和 Realms 任务中使用原版死灵 Buff。由房主为全队选择统一奖励模式及 Buff 上限，提供预选、地图进度和个人击杀奖励三种玩法。

[size=4][b]预选模式[/b][/size]

任务开始前打开天赋树，使用分类筛选、已选视图、原版图标及详情面板选择 Buff。每个 Buff 消耗 1 点，全队统一上限为 0–64。流派、职业、技能及天赋要求遵循原版数据。进入任务后锁定编辑。

[size=4][b]进度模式[/b][/size]

开局从三条公共死灵路线中选择一条，并立即获得基础 Buff。后续路线 Buff 自动发放，第 4、7、10 个奖励为传奇三选一。

包含开局奖励在内，最多获得 10 个 Buff。路径节点为 8%、16%、24%、32%、40%、50%、60%、70%、80%，最后奖励提前到任务结束之前。没有线性路径的地图，使用主要目标开始事件发放有上限的阶段奖励。路径与目标不重复计奖；死灵试炼任务使用波次事件。时间流逝不产生奖励。

[size=4][b]竞争模式[/b][/size]

开局选择路线，每名玩家随后通过击杀累计个人进度。每满 100% 自动获得所选路线的 Buff，优先发放基础 Buff。路线耗尽后，后续奖励变为符合条件的公共／职业 Buff 三选一，不依赖波次。已获得 Buff 不会重复进入候选。全队统一上限为 0–64，溢出进度保留。

默认击杀进度：普通敌人／尸潮 0.25%、特感 5%、精英 2.5%、普通 Boss 50%、虚弱 Boss 50%、连长／双子 50%。房主可统一调整这六类数值，支持两位小数。机器人击杀不计入真人玩家进度。

DMF 可选择自己的作战进度显示：小型进度条、进度条＋百分比、仅百分比或不显示。隐藏进度不会停止奖励，也不会隐藏抽选卡片。

[size=4][b]路线与 Buff 抽选[/b][/size]

三个紧凑的动画卡片出现在画面中央偏上。按 Ctrl＋1、Ctrl＋2 或 Ctrl＋3 选择，不停止玩家移动、不接管鼠标；其他菜单及文字输入优先。

每次选择有 60 秒，超时由房主随机选择。后续机会排队等待，每次轮到时重新获得完整 60 秒。候选遵循原版路线与职业条件；不足三个时只提供剩余可用项，池子耗尽后停止抽选。

按 Tab 可在原版死灵分类查看已经获得的 Buff。进度及竞争模式下，天赋树中的死灵按钮置灰，并显示同步后的奖励数量。

[size=4][b]房主设置与 Realms[/b][/size]

没有 Realms 时，在 DMF 调整模式、全队上限和击杀权重。使用 Realms 时，房主在准备列表中拥有一行全局死灵控件，空房间也可操作。不提供逐玩家模式或点数覆盖，可与天赋点管理器的逐玩家控件共存。

点击数字可输入或粘贴，回车或点击其他位置确认，Esc 取消。Realms 加减控件长按 400 毫秒后连续调整。

客机遵循房主规则。部署状态显示就绪、未安装／不兼容、资源加载、已禁用及连接中断。未就绪或掉线客机不会阻塞其他玩家；同局中以相同角色重连可以保留已获奖励，其他角色或任务使用独立状态。候选及奖励由主机管理，过期或重复回复不会额外消耗奖励。不提供房主迁移。

缩小上限会限制生效 Buff，并保留原有选择记录；提高上限可恢复保留的选择。任务中切换奖励模式会开始新的奖励流程，建议开局前确定模式。

[size=4][b]使用前提与兼容[/b][/size]

需要 Darktide Mod Loader、Darktide Mod Framework 和 SoloPlay。玩家房主联机可使用 Realms，天赋点管理器为可选。英文、简体中文和繁体中文跟随游戏语言。

DMF 开关与自定义死灵 Buff 开关都需要开启。功能默认关闭，默认为预选模式、32 点全队上限。关闭 mod 会移除界面及已应用效果，并保留保存的选择。

Buff 使用原版模板、编号及任务 Buff 管理器，遵循原版叠加与适用规则。在死灵试炼任务中，本 mod 接管奖励流程并避免原版弹窗接管操作。替换同一奖励流程的其他 mod 可能冲突。本 mod 不改变官方匹配的永久成长。
