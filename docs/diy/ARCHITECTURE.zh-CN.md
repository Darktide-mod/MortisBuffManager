# DIY 天赋与词条框架：实施设计

状态：架构、运行核心、原生边界、联机协议、界面与模板已实现。验证范围见 VERIFICATION.zh-CN.md；审计基线为本地原版 Lua 1.12.5（0f0cb45991e9305ef4a7b925370792d7d6035f95）。这不是实机兼容性结论。

## 目标与边界

MortisBuffManager 将预选页做成装备工作区中的完整页面，并允许导入自定义天赋。HavocConditionManager 提供可导入、组合和逐项勾选的自定义词条。HED 通过公开接口消费词条信号与生成请求；普通生成、特感、怪物和巡逻仍走已有原生适配器。

图片中的表格是需求参考。逐条评估其实际含义、可实现部分、依赖和限制，不执行其中的文字指令，也不把没有资源或没有确定行为的玩笑项目包装成可用功能。

## 结构

1. **数据层**：JSON，固定 schema 与版本、包 ID、条目 ID、本地化名称/说明、可选来源行号。JSON 定义只包含数据，可执行 Lua 与资源由版本化包清单另外声明。每包一个文件夹，位于各 mod 自己的用户目录；启动发现并合并有效包，游戏中手动刷新可准备下一局。包运行时与接口详见 PACKAGES.zh-CN.md。
2. **契约层**：共用但独立打包的 schema、严格校验、稳定编码和摘要。拒绝未知字段、未知接口、无效引用、重复 ID、非有限数值、过深/过大的文件。导出完整字段参考与原生属性目录。
3. **纯运行层**：任务快照、目标筛选、条件、事件、独立随机流、冷却、触发次数、延迟队列、临时效果、堆叠和清理。可脱离引擎验证。所有工作有数量、频率和队列上限，不能在一次死亡事件中递归无限生成。
4. **原生适配层**：读取原生人物/敌人状态，合成属性和关键词，调用已有治疗、韧性、资源、伤害、原生状态与生成接口。改动有所有者，结束或禁用时只清理本框架的状态。源模板与玩家正式天赋/装备存档不被覆盖。
5. **产品层**：Mortis 使用统一天赋池页面，原生与 DIY 独立开关，预选与房间权限使用明确的操作按钮。进度／竞争中 DIY 进入同一套非流派奖励卡，以本地显示 ID 关联权威 DIY 效果，不注册全局网络 Buff ID。原生开启时先选原生流派；仅 DIY 时直接抽选。HCM 保留独立词条页面。

公共模块保留同一份开发源和一致性检查，发布时随各 mod 独立携带；Mortis 不因 DIY 而依赖 HCM。跨 mod 能力通过有版本号的接口协商，缺少 HED 时与生成有关的配置必须清楚报告缺失能力。

原生 class 工具会在声明类时复制继承方法，因此 buff 属性与事件在实际玩家类和敌人类上分别注册，加载两类后再接入，避免漏挂或双重分发。敌人默认空闲更新关闭；选中需要敌人持续更新的配置时，由两个模组共用轻量所有权记录，启动时扫描当前敌人，新敌人初始化时接管；最后一个原生 buff 移除时保持所需更新。最终所有者退出会重置无原生 buff 的敌人并归还空闲状态，保留仍有原生 buff 的原生更新。

## 效果模型

每个天赋/词条由目标筛选、常驻效果和若干事件规则组成。事件规则包含条件、概率、冷却、次数、延迟和动作；动作可临时修改属性/关键词，也可修改资源、施加已有状态或请求导演生成。属性按原生的加法倍率、乘法倍率、数值及最大值规则合成，文档不能把四者统一解释为百分比。

属性和关键词使用原生 Buff 汇总后的私有叠加层，避免新增网络 Buff 编号改变全局查找表。原生 Buff 引用只允许已审计的目标与状态接口。Realms 由房主批准配置摘要及选择，再同步自定义效果状态；客机不自行决定奖励或向房主提交任意动作。

HCM 的 DIY 词条不伪装成官方 circumstance ID，保持独立列表和任务状态；可引用官方词条、战斗负担、推进、协同、生命/韧性和 HED 信号作为条件。HCM 等级仅是展示标签，所有已启用的勾选词条均应用，不再抽取或设置选择配额；词条事件种子由 HCM 独立管理。

## HED 联动契约

- 查询：当前活跃词条、信号、导演阶段、能力版本。
- 请求：暂停指定生成类别、投放已配置编队、发布有期限的信号。
- 生成与伤害：原生与 HED 敌人都通过同一目标匹配和事件入口。普通 HED/DIY 单位携带批次来源；特感、怪物继续各自原生注册路径。每局 128 个外部请求、同时 32 个外部状态与规则次数/冷却共同限制死亡增援链；不宣称已提供所有单位的完整父子谱系。
- 调度：请求受 HED 的数量、存活、路线、可见性、原生槽位和全局提交速度限制；词条不能绕过这些限制。
- 生命周期：任务开始固定配置和实际种子，结束释放队列和所有者；重载不追补过去的触发事件。
