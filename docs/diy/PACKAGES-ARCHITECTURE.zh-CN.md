# DIY 包与脚本接口

本次同时修复 Realms 尚无 game_mode 时导入按钮被错误禁用的问题，并把新包作为词条／天赋共同的发布与加载单元。两个模组各自携带运行库，不互相依赖安装。

## 磁盘与发现

每个包位于 `%APPDATA%/Fatshark/Darktide/<模组名>/diy/packages/<包ID>/`。包目录必须有 `package.json` 和 `definitions.json`，可有 `lua/`、`resources/`；清单明确列出全部文件。禁止越界路径、重名路径及目录链接。不接受把松散 Lua 当成包直接执行。

启动自动发现、验证并载入有效包；刷新用于游戏运行时新增／修改包。数据条目载入与实际获得效果分开：脚本只在相应技能／词条生效时运行。当前任务使用已冻结的包内容，刷新结果用于下一局，绝不在一局内替换脚本。原有 JSON 先转换为规范目录，原文件保留。首次启动生成入门包，已有同名包不覆盖。

## 稳定契约

包格式版本、Lua API 版本、包自身语义版本分别声明。API 使用 major/minor；不支持的 major 或所需 minor 会拒绝加载。依赖声明包含包 ID 和版本范围，可声明冲突；按依赖顺序解析，缺失、循环与版本不符显示明确错误。扩展元数据仅放入命名空间化的 `extensions` 字段，未知核心字段不默默忽略。

允许同时载入多个包。包内 ID 不需要全局唯一；运行库用稳定的包 ID＋条目 ID 命名空间生成游戏内部 ID，并保存来源映射。各包自己的互斥组和信号默认隔离。依赖的 Lua 导出通过显式包依赖访问，避免向游戏全局变量注册通用名称。

## 脚本与资源

Lua 作为可信本地模组代码执行，能调用原生游戏 API；这不是安全沙箱。每个任务为包创建独立 Lua 环境及模块缓存。入口返回 API 版本、按条目 ID 索引的回调和可供依赖使用的 exports。回调包括启用、按间隔更新、订阅事件、停用；只有当前获得／选中的条目会订阅。原生伤害、属性叠加、生成、信号等常见操作通过已验证的公共 API 调用，并复用现有引擎。

提供资源字节读取、包内模块与已声明依赖模块加载、清理回调。API 1.1 增加 diy_assets：声明资源在配置库扫描时按内容生成可供 SimpleAssets 读取的不可变副本，词条按名称加载；原生结果在管理器进程内复用，使用者作用域负责回调失效与登记的对象清理。外部图形加载依赖 SimpleAssets v2，关闭使用者不等于底层卸载，也不支持任意模型／音频格式转换。详见 ASSETS.zh-CN.md。

原生事件按订阅索引分发，更新频率有下限，未获得的条目没有周期性回调。错误隔离到所属包／条目，并执行登记的清理；通过公共 API 产生的临时效果跟随条目撤销、死亡和离局释放。任意原生调用的额外副作用由作者登记清理。

## 联机与验证

Lua 游戏逻辑只在本地单人权威或 Realms 房主运行；客户端继续接收原版同步或已有聚合属性协议，不接收／执行网络传来的 Lua。死灵入池校验覆盖条目、包内 Lua、资源和依赖的 SHA-256 指纹，保留现有全房间一致性规则。包编译与 IO 不进入逐帧／击杀热路径。

检查覆盖真实 Windows Unicode 包目录 IO、原子写入、旧 JSON 转换、启动发现与刷新、Realms 无 game_mode 准备房间、依赖与命名空间、Lua 生命周期、资源读取、错误清理、各奖励模式、联机指纹，以及旧发布文件不变。实机多人验证单独标注，不以离线替身代替验收结论。

包格式 2 以单个词条为安装和管理单位，独立目录中仅有一个定义条目，并包含自己的 Lua 和资源。entry_namespace 保留旧合并包的稳定词条标识；旧入门包经验证拆分后移入 package-backups。格式 1 只作为兼容读取入口，新入门包、导出模板和多条目 JSON 导入均逐词条创建。
