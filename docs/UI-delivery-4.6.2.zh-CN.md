# 死灵试炼 UI 4.6.2：安装版本与功能核对

2026-09-12 的安装文件和最新启动日志均确认：本机仍加载 MortisBuffManager 4.6.0。此前四分类、流派过滤和滚轮浏览的改动在独立的 MortisBuffManager 4.6.1 发布包里，没有随上次交付的 HavocConditionManager ZIP 更新。因此不能把 HCM 更新成功当作死灵 UI 也已更新。

本次单独交付 MortisBuffManager 4.6.2，并核对源码及最终 ZIP：

- 主浏览标签只有「可入池」「DIY」「已选择」「不可入池」，按钮附数量，没有旧的「全部」「原生」浏览标签。顶部的「原生天赋」开关仍用于启用原生池，不属于浏览标签。
- 第二行按官方来源区分公共、职业和流派；「可入池」只展示当前配装、路线与房间规则允许的天赋。「DIY」及「不可入池」保留对应内容供检查。
- 更改实际流派后，清除新配置下不能入池的原生及 DIY 预选；仅切换浏览分类不会改动保存的选择。
- 「已选择」与其他标签并列，选中行使用勾选和金色；不再追加冗长的已预选文字。
- 天赋列表与详情各自使用鼠标滚轮／滚动条，天赋浏览不分页。
- 离开死灵天赋页后停止该页的输入和绘制；处理共享窗口关闭时子页面已被原生销毁的情况。
- 本次另补旧筛选状态迁移：保留下来的 `all`、`native` 或其他未知值会重置到「可入池」，不会通过兼容模型再次显示完整列表。

用本机 Realms Loadout 0.5.1 的窗口代码作为固定测试素材，在原生 UI 处理器中反复切换天赋、配装、外观、锻造和死灵页，每种窗口 4,800 帧均保持当前页面，不重新打开旧死灵页。还检查了四分类、流派切换清理、300 项长列表、原生滚轮／拖动和三种语言的 48 种布局。

这些是离线源码／原生逻辑检查和界面布局预览，不能替代实际游戏渲染、帧率与联机验证。发布脚本通过 Vortex 安装布局检查，但没有部署本机文件。

安装时需要同时更新两个独立模组：本 UI 使用 MortisBuffManager 4.6.2；动画修复使用 HCM 4.4.6-test.8 及外部狂暴攻势 1.6.5。主模组 UI 代码要在重新加载模组后生效；只刷新狂暴攻势 DIY 包不会加载新死灵界面。下次启动日志应显示 `MortisBuffManager` 版本 `4.6.2`。
