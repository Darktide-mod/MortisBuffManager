# DIY 敌人增益销毁修复

对应版本：HavocConditionManager 4.4.3、MortisBuffManager 4.5.2。两个模组分别提供独立安装包；同时使用时，请一起更新。

启用「狂暴攻势」等需要持续更新敌人增益的 DIY 词条后，携带原生增益的敌人被移除时，旧版可能报错：`Cannot access property "update" on destroyed object of type MinionBuffExtension`。

原因是原版先注销组件，再销毁组件并清除增益。DIY 在增益移除回调中重新启用更新，没有区分普通增益到期和组件销毁，导致已销毁的组件残留在更新列表中。此问题无需异步物理即可复现。

修复在组件销毁开始时设置标记，阻止其再次登记更新，并清除 DIY 对该组件的更新所有权。后续清理会跳过已销毁组件，存活敌人的增益正常到期仍会保留必要的 DIY 更新。HCM 与 MBM 使用相同逻辑，均已修复。

回归检查使用原版组件删除、增益移除和类对象销毁方法，覆盖无增益、单增益、多增益、两个模组单独启用及共同启用、加载顺序、普通增益到期、剩余更新提供者、重复进入任务和遗留已销毁引用。原先的闪退场景已通过离线检查；尚未进行游戏内实战复测。

本次仅生成发布产物，不更新游戏目录或 Vortex 中的本地安装，不更改 RealmsPhysicsPatch 或其选项。安装新版并重启游戏后生效，已有词条包和选择可以继续使用，无需重新解压模板。
